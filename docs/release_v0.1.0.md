# v0.1.0 - Portfolio-ready NLP document intelligence release

## Included

- LEDGAR data pipeline
- Optional CUAD preparation path
- TF-IDF + Logistic Regression baseline
- Optional transformer training pipeline
- Evaluation and error-analysis outputs
- Rule-based risk scoring engine
- Semantic clause search
- FastAPI service
- Docker and docker-compose
- Tests and GitHub Actions CI
- Honest limitations and legal disclaimer

## Limitations

The project does not include downloaded datasets, trained model weights, or fabricated benchmark numbers. Outputs are for document analysis and risk triage only.
